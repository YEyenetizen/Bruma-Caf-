# Bruma Café - Página Web de Comercio Electrónico

## Descripción del Proyecto

Bruma Café es una página web moderna y profesional para un negocio ficticio de bebidas artesanales ubicado en Playa del Carmen, Quintana Roo. El sitio integra todos los requisitos del proyecto integrador final, incluyendo comercio electrónico, múltiples formas de contacto y métodos de pago.

## Características Principales

### ✅ Páginas Implementadas

1. **Página de Inicio (index.html)**
   - Nombre y logotipo del negocio
   - Bienvenida e introducción atractiva
   - Descripción general del negocio
   - Imágenes representativas
   - Productos destacados

2. **Catálogo de Productos (catalogo.html)**
   - Listado completo de 5 bebidas artesanales
   - Precios en MXN
   - Descripciones detalladas
   - Ingredientes y presentación
   - Opción de personalización

3. **Ubicación (ubicacion.html)**
   - Dirección: Av. Central #123, Playa del Carmen, Quintana Roo
   - Mapa de Google Maps integrado
   - Información de contacto directo
   - Horarios de atención
   - Puntos de referencia cercanos
   - Información sobre accesibilidad

4. **Contacto (contacto.html)**
   - Formulario funcional de contacto
   - Número telefónico: +52 984 567 0199
   - Correo electrónico: BrumaCafé23@gmail.com
   - Enlaces funcionales a redes sociales (WhatsApp e Instagram)
   - Información de disponibilidad

5. **Métodos de Pago (pagos.html)**
   - Transferencia bancaria
   - Tarjeta de crédito/débito
   - PayPal
   - Efectivo
   - Depósito por aplicación
   - Proceso de compra paso a paso
   - Políticas de seguridad
